# 双手及腕部相机安装方向调整（1.4.0）

在上一版模型的基础上，将左右两侧的手／法兰组件和腕部相机组件分别沿前臂纵向中心轴旋转 180°。
该轴在各自的 `wrist_roll_*_Link` 坐标系中为经过 `[-0.0317, 0, 0]` m 的局部 Z 轴，
与有驱动的 wrist-roll 关节轴不同。只修改 `left_adapter_mount`、`right_adapter_mount`、
`left_wrist_camera_reference_joint` 和 `right_wrist_camera_reference_joint` 四个固定关节的姿态。
安装根部位置、手与法兰之间的连接、相机内部变换、网格、驱动关节限位及头部相机均保持原样。

## 更新原因

目标桌面操作姿态为右手掌朝下、手指朝机器人面向的方向。此次调整安装方向，目的是让机械臂达到
该姿态时具有更大的关节限位余量；不改变物理关节限位。本次发布验证了安装几何，尚未定量证明
限位余量或可行域增大。需要针对新模型重新进行 IK 和碰撞评估；不同安装方向的旧评估不能作为
本版的验证结果。

## 文件及坐标说明

- `assets/assembly.urdf`：更新后的默认模型，保留公开仓库 `world_to_base` 的 Z = 1.20 m。
- `assets/assembly_bilateral_axis180.urdf`：用户确认的生成文件原样副本，SHA256 为
  `537f31a798ddb05d1f29e2b5eeede63d47af3d9ff519f40907a24e757f5bbf44`。
  它继承的世界原点高度为 Z = 1.20035 m；除这一处 0.35 mm 的世界平移外，与默认模型相同。
- `assets/scene.xml`：同步安装姿态的 MuJoCo 场景，桌面顶面 Z = 0.75 m，
  比默认模型的机器人基座原点低 0.45 m。
- `assets/mount_rotation.json`：旋转来源及验证记录。

URDF 只包含机器人，桌子由场景单独定义。下图桌面中心位于基座局部 +X 方向 0.60 m，
横向偏移为零，桌面顶面比基座原点低 0.45 m。图中使用原样 URDF，并在场景中显式放置机器人，
不采用文件继承的世界偏移。双臂均处于零位；这张图不是掌心朝下的任务姿态，也不是 IK 可行性
