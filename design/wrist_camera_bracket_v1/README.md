# 新设计腕部相机支架 V1

这是参考四张安装图片和已核对接口孔位的新设计。默认 **直臂80 mm、安装片40°**，相机本体与螺钉均不包含在支架几何中。它是未认证的加强打印原型，材料及实机紧固方式仍需确认。

## 交付

在项目根目录运行 `bash view_camera_bracket.sh` 只看支架，`bash view_camera_robot.sh` 看整机装配；`bash view_cameras.sh` 看三路RGB-D并实际重建长度/倾角参数。首次构型重建可能需要数秒。参数保存到独立用户配置，不改默认80/40。

- `whole_bracket.step`：完整一体支架，标准STEP，毫米。
- `whole_bracket_mm.stl`：完整一体支架，毫米，可用于切片准备。
- `whole_bracket_m.stl`：同一三角网格缩放至米，用于仿真；不要把它按毫米直接打印。
- `parts/`：腕连接座、支撑臂、相机板/根部加强段的三个语义分区，各有STEP、根坐标毫米STL及body-local米制STL。分区不是三个无需连接件即可拼装的打印零件；实际制造目标是完整一体件。
- `manifest.json`：参数、孔轴、坐标、体积、估计质量/惯量和全部文件指纹。
- `cad_preview.png`：三段着色预览。
- `bracket_overview.png`：MuJoCo中的三段着色几何预览，不含相机。
- `options/L080_T060/`：相同80 mm臂长、60°安装片的成像对照结构。默认仍是80/40。
- `parameter_validation.json`：实际STEP参数不变性与边界样例检查。
- `assembly_review.md`、`strength_review.md`：独立装配/结构核查及其限制。

## 几何

| 区域 | 主要尺寸 |
| --- | --- |
| 腕部圆弧座 | 内R30.8、外R35.8 mm，Y约-10.5至-0.5 mm；相对官方R30.5外圆预留0.3 mm径向设计间隙 |
| 两个腕安装孔 | θ=30°/150°、轴高Y=-4.5 mm，通孔3.4 mm；两轴不平行。外侧6 mm平底沉孔形成垫圈/螺钉头支承面 |
| 直支撑臂 | 总宽24 mm，底板厚6 mm；双侧肋各宽3 mm、额外高8 mm，沿整段臂长；纵向边圆角0.8 mm |
| 相机安装片 | 主板40×42×4 mm；两孔直径3.4 mm、间距20 mm；带一体根部连接和两侧加强过渡 |
| 已有紧固件避让 | θ=15°/105°处9.5 mm工具/螺钉头避让；不是新增安装孔 |

根坐标与手部转接件肩台一致：X横跨腕，Y沿腕轴朝指端，Z朝支架所在侧径向外。`θ=atan2(Z,X)`，所以正θ对应标准右手系 `Ry(-θ)`。

直臂建模参考轴从 `[0,0,61]` 到 `[0,L,61]` mm。安装片pivot为 `[0,L,62]` mm、倾转轴为X；正倾角使板远端抬高，板下相机光轴朝向更远端。板局部两孔中心为 `(±10,32,0)`，相机背部接触面为Z=-2 mm。

腕侧3.4 mm通孔仅适配已核对的轴线位置，不证明原机是某种螺纹。原机螺纹、可用啮合深度与螺钉长度需实测。相机背面M3深度参考为4 mm，螺钉总长需结合板厚、垫圈和实际牙深选择，避免顶底。

## 参数化生成

在项目根目录运行：

```sh
.cad-venv/bin/python scripts/design_wrist_camera_bracket.py \
  --length-mm 80 --plate-tilt-deg 40 \
  --output-directory design/wrist_camera_bracket_v1
```

`length_mm` 支持20–150，仅改变沿+Y的直臂长度并平移远端板；腕座保持不变。`plate_tilt_deg` 支持0–75，仅重建板和附属根部过渡，腕座、直臂不转。修改参数需重新生成真实CAD；不能仅旋转旧板网格而保留旧根部过渡。

每次生成检查完整STEP回读为单一有效实体、毫米/米STL封闭、三语义区体积划分及指纹。低倾角处可能出现圆角交界的极小分区边缘碎片；仅允许去除总量小于0.05 mm³的此类边缘，并在清单中记录数量与体积，然后重建完整实体。默认80/40无需该清理。

默认密度1250 kg/m³仅是显式建模假设，不代表已选定某个材料或打印参数。默认估计总质量约40.17 g，其中腕座11.28 g、直臂19.15 g、板及根部9.75 g。没有据此宣称150 mm长臂的挠度、层间强度、螺钉或腕座连接已通过验收。

## 相机独立装配

`plate_frame` 的平移为 `[0,L,62]` mm、姿态为Rx(倾角)。D405的bottom-screw frame相对plate frame：

```text
translation = [0, 53, -10.35] mm
rotation = [[0,1,0], [0,0,-1], [-1,0,0]]
```

它把D405背面两点 `(-8.35,±10,21)` mm对应到支架背面接触点 `(±10,32,-2)` mm，相机光轴朝plate -Z。相机必须作为独立几何/URDF链接装配。
