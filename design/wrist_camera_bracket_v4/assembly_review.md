# V4 拇指侧安装及板杆夹角：独立审核

本版最终定义：两手均安装在拇指侧的小孔对，用户的 15° 指相机板与支撑杆的夹角。它不是 V3 中板相对水平面的 Rx=15°；本版对应实际 CAD Rx=75°。V3 的旧解释和结果不作为本版验收。

## 截图与左右方位

参考图 `/tmp/codex-clipboard-GWQFEn.png` 中，大连接件固定孔靠近右箭头的小孔。按场景红色测试块的位置，图更可能是右手视图；最终安装方位另有与截图无关的 FK 证据：在未旋转的 adapter 坐标 A 中，左右 thumb_CMP 均 X=+19.5 mm、thumb_CMR 均 X=+29 mm，小指 MCP 均 X≈-37.39 mm。因此左右拇指侧都是 A+X，右侧不能继续叠加旧的 Ry(pi)。

独立从官方左右 wrist_roll STL 取截面，目标 theta_A=330°/30° 均为约 2.5 mm 的小孔芯；theta_A=15° 另为约 4.5 mm 的连接件固定孔，外侧还有扩大的沉孔。小孔与大孔没有混用。

## 新座的孔距与安装变换

| CAD局部孔角 | CAD孔中心，mm | 安装后A孔角 |
|---|---|---|
| 60° | (15.25,-4.5,26.4137748) | 330° |
| 120° | (-15.25,-4.5,26.4137748) | 30° |

两个孔的角间距为60°，中心距30.5 mm；旧座120°孔对的中心距52.82755 mm不适用。新窄座弧段为52°–128°，并保留3.4 mm通孔和6 mm沉孔承压座。

左右共同采用：

```text
t_wrist_bracket = (-0.0317,0,-0.0812) m
R_wrist_bracket = Rx(-pi/2) @ Ry(+pi/2)
                = [ 0  0  1
                   -1  0  0
                    0 -1  0 ]
可用 URDF rpy = (-pi/2,0,-pi/2)
```

这样杆的局部 +Z 指向 A+X 拇指侧。被用户指定覆盖的大孔 A15° 位于新座局部105°，处于新孔60°与120°之间，距离120°小孔只有15°，与截图的大/小孔关系吻合。覆盖仅表示取消该维修通道，不代表删除机器人螺钉或认证剩余紧固件强度。

## 真实15°板杆夹角

用户角度 a 与内部板旋转的关系为 `CAD_Rx = 90° - a`。长度80 mm时枢轴仍是支架系 `(0,0,115.8)` mm。

从实际 plate STL 的主平面三角形法向和实际 stem STL 的主惯量轴求得：

- 板长方向：(0.0000000000, 0.2588190903, 0.9659258142)。
- 杆方向约为：(0,0,1)。
- 实际点乘：0.965925814171；cos(15°)=0.965925826289。
- 实体测得板杆夹角：15.00000268°。
- 两侧 URDF 的板长方向与杆轴直接点乘，各得到约 14.9999999998°。

这个检查使用实际三角面、实体惯性轴和URDF坐标轴，不是只检查参数字段是否写了15。板向正确的一侧倾斜，没有用105°的反向姿态冒充同样的锐角。

## 相机接口与配合检查

D405仍是独立link/mesh，通过背面两个M3孔固定；底部1/4-20孔不使用。plate到官方camera_bottom_screw参考坐标仍为平移 `(0,53,-10.35)` mm及以下旋转：

```text
R_plate_bottom = [ 0  1  0
                   0  0 -1
                  -1  0  0 ]
```

相机背面孔映射到plate `(±10,32,-2)` mm，后背接触面Z=-2 mm，前盖Z=-25 mm。镜头朝plate -Z，顶部朝plate -Y，USB位于plate -X侧。相机实际URDF外观包络与该位置一致，且包络开内部没有支架三角面或实体中点；允许安装后背接触。

左右新窄座与官方腕模型在局部Y=-10.4、-8、-5、-0.6 mm八个闭合截面上，相交面积均为0 mm²。大孔A15°前方的27个覆盖采样点全部落在支架实体内。目标小孔的真实轴线、孔径与大孔区别另行检查通过。
