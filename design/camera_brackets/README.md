## 已准备的工作

- `scripts/camera_bracket_cad.py`：只读的源格式检查与标准 STEP BRep 特征提取工具；遇到非标准源返回明确状态，支持用真实 OCP STEP 读取器验证。可读 STEP 会列出所有实体、平面法向及圆柱孔轴，仍需基于实际几何识别杆与连接板。
- `.cad-venv`：独立 CAD 依赖环境；不会升级仿真主环境 `.venv` 的 NumPy。
- `source_inspection.json`：可复现的原件指纹和读取结果。
- `assembly_schema.pending.json`：与 URDF 分支对接的待填接口，未知几何字段均为 null，不含虚构模型。

在项目根目录运行：

```sh
.cad-venv/bin/python scripts/camera_bracket_cad.py --probe-ocp
```

非 STEP/读取失败时退出码为 2，并保留结构化诊断。此脚本目前是读取/检查工具，**不是已经完成的相机支架参数化生产器**。

## 解除阻塞所需输入

需要 CAD 读取器能够解析的标准 STEP 源数据。当前缺少的是实际可读的 BRep，不能由安装另一个 Python 包或推测尺寸替代。

拿到 BRep 后按以下含义继续实现，默认零增量必须几何还原来源：

- `length_delta_mm` 只改变支撑直杆长度，保持腕连接座不动，同时平移远端相机板连接点。
- `camera_plate_tilt_delta_deg` 只围绕杆与相机连接铁片交界处的实测/几何确定轴转动铁片，不改变整支架和腕部姿态。
- 输出腕连接座、支撑杆、相机板的部件几何与刚体变换，并分别记录实际连接孔、杆轴、板 pivot 和倾转轴。

当前没有输出假冒原支架的 STEP/STL，也没有把占位相机支架当成真实 CAD 交付。
